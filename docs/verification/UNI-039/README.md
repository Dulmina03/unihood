## Confirmed defects and corrections

- A new regression failed because the comparison contract accepted a locality in HIDDEN mode. It now rejects hidden locality, community PUBLIC_MAP, official community price/vacancy and community unit facts. Existing private entrance/essentials exclusion remains strict.
- Comparison could fall back to uncurated listing descriptions/canonical names when a reviewed advertisement preview was absent. It now requires the current curated preview and selects its title/summary only. Comparison unit labels/types also come from the approved template, matching the existing inventory projection; raw legacy unit labels/types are never forwarded. A real SQL private-text canary guards this boundary.
- Comparison previously queried official unit rows for community recommendations. It now skips that query entirely. Owner unit confirmations must match current unit/vacancy revisions and server time, preventing obsolete confirmations from resurfacing.
- Essentials/comparison eligibility now checks current listing visibility and owner authority. Essentials requires the current entrance consent timestamp; comparison joins only a current-consent entrance. No private location fallback is used.
- Open comparison/essentials views previously retained a one-time response indefinitely. They now use the map layer's five-second revalidation bound plus focus, visibility, page restore and network events; changed keys remove old geometry/proximity immediately while refreshing. Cleanup aborts requests and clears keyed results; private→public transitions cannot revive old essentials. No client geometry cache or persistence was added.
- Partial browser tests expected nonexistent `.compare-card` elements and text absent from the existing table. Assertions now inspect the existing accessible comparison table and actual response projections; the approved design was preserved.

## Coverage and privacy boundaries

- **Public lists, advertisements and detail:** strict variant contracts and API tests cover owner HIDDEN/AREA_ONLY and community recommendations, null geometry/routes/distances, permitted locality, canonical IDs, pagination and spatial-query rejection. Existing `boardings.spec.ts`, `boarding-projection.spec.ts` and `scripts/lib/test-boarding-advertisements.mjs` additionally test actual private geometry/ciphertext/unreviewed-text canaries and revoked/disputed/archived exclusion. PUBLIC_MAP currently uses the dedicated map/comparison surfaces; the private advertisement list rejects `visibility=PUBLIC_MAP`, and its detail endpoint returns 404 for public-map records. This is recorded behavior, not a claim of a new public advertisement implementation.
- **Map/search/filter/proximity:** dedicated map SQL and real PostGIS enforce consented owner PUBLIC_MAP only. Private mode comparisons contain null entrance/essentials. Matrix SQL tests use an explicitly synthetic public entrance, unrelated private-coordinate canary and mismatched consent timestamp. Existing map regression exercises actual owner visibility HTTP changes, canonical identity, concurrent revision conflicts and rollback after an injected failure. The matrix's own in-transaction SQL transitions supplement that HTTP test; they do not replace it.
- **Routes and generic lookup endpoints:** `/api/v1/routes`, `/essentials` and `/search` are not implemented at this phase and are tested as sanitized 404s with no database lookup. Existing boarding title/locality search is separately tested. These are absence/denial checks, not routing-provider verification. No private route, precise distance or inferred pin is computed.
- **Media/contact:** existing `boarding-privacy-core.spec.ts`, `boarding-privacy-http.spec.ts`, browser media/contact cases and real `test-boarding-privacy.mjs` run unchanged: actual synthetic EXIF/XMP stripping, encrypted fictional contact, wrong-key/tag failures, private quarantine, consent revocation, interrupted staging, capability/IDOR and deployed-write denial. No real phone, property, malware-scanner approval or public media/contact delivery is claimed.
- **Share/SEO/cache:** noindex metadata, no-store API/proxy responses, canonical-ID links and private DOM/network projections; browser comparison revocation and reload; existing map revocation clears stale selection/share state. Geometry is not persisted in local/session storage. Five-second refresh is bounded client revalidation, not recall of already-copied external content or instantaneous removal from another offline browser.
- **Owner authority:** existing property-specific capability and cross-property tests remain; the new matrix reinforces student official-field denial, production adapter denial and generic nonreflective errors. Current local/test issued actors are synthetic and production protected writes remain closed.
