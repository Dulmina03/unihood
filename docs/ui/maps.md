# MapLibre integration — UNI-013 / UI-03

`/explore` now loads MapLibre GL JS 6.18.0 on the client when a credential-free provider is configured. Existing Campus Teal navigation, desktop results rail/preview, tablet rail, mobile results sheet, Map/List and validated URL state are preserved. No map is initialized in list mode. No later discovery, boarding, POI, route or registration workflow is added.

## Configuration and provider review

Set `MAP_PROVIDER=openfreemap` and optionally `MAP_STYLE=liberty` or `bright` in the local environment, then restart web. `.env.example` defaults to `MAP_PROVIDER=disabled`. Existing .env is preserved. Empty/disabled selects a clear list fallback; unknown providers/styles fail closed with generic configuration wording. The old bootstrap `NEXT_PUBLIC_MAP_STYLE_URL` is intentionally ignored. No arbitrary provider URL, token, private API key, identity header or destination supplied through URL query state is accepted.

The dynamic server page projects environment configuration into only `{kind, style}`; full environment objects never reach client props. Changing to a different provider requires a reviewed adapter/resource allowlist, attribution and terms update, rather than inserting a credential-bearing URL. Both Next bundlers remain configured normally; no SSR import of the map engine is needed.

Provider review on 16 November 2026:

- [OpenFreeMap service](https://openfreemap.org/) permits commercial browser use, publishes no online map-view/request count limit, requires no registration/API key/cookie, and offers no SLA. This differs from the OSM Foundation's public tile service; UniHood does not use unrestricted public OSM tile endpoints.
- [Terms](https://openfreemap.org/tos/), updated 14 October 2026, prohibit disruptive/unapproved automated collection. Offline downloads have explicit per-download ceilings of 3,000 tiles or 50 MB, four parallel requests and an identifying User-Agent; larger downloads need provider contact. UniHood implements no bulk download, prefetch area, offline pack, proxy or service-worker tile cache. The terms require an adult authorized integrator; they do not impose that age restriction on embedded-map viewers or decide UniHood registration policy.
- A direct read of the configured Liberty style returned HTTP 200 with CORS `*` and `Cache-Control: public, max-age=86400`. Resource origins were checked: style/sprite/font/planet/Natural Earth resources use `tiles.openfreemap.org`. Browser HTTP caching follows provider response headers; expired tiles may revalidate. No application cache retention guarantee or unrestricted offline license is inferred from those headers.
- [Provider licenses](https://github.com/hyperknot/openfreemap/blob/main/LICENSE.md): project MIT; OpenMapTiles code BSD-3-Clause/design CC BY 4.0; Liberty/Bright derived style code BSD-3-Clause/design CC BY 4.0; OSM map data has its own [copyright/ODbL obligations](https://www.openstreetmap.org/copyright). Noto fonts are OFL, Maki icons CC0 and Natural Earth data public domain. Source attribution is shown persistently and links to OpenFreeMap, OpenMapTiles and OSM; inherited style attribution is not treated as optional.
- Browser token restrictions are **not applicable** to this chosen service: there is no token or account credential. Private credentials must never be placed in client configuration. A later keyed provider needs separate verification of permitted browser tokens, origin restrictions, quotas and caching terms.
- [Privacy policy](https://openfreemap.org/privacy/) covers embedded maps, provider/CDN request processing and possible error/security logs. The provider necessarily receives network requests and the viewed tile area. UniHood sets no-referrer on map resource requests, sends no custom account headers and uses same-origin credentials mode, which omits application cookies on cross-origin provider requests. It never sends private boarding data or device location.

These are implementation evidence from published sources, not a blanket public-launch legal approval. Recheck terms/resource hosts when enabling a deployment or upgrading styles. Provider outage/discontinuation remains supported by list fallback. No paid account, billing agreement or subscription was created.

## Public data and synchronization

Universities/campuses/entrances continue through the existing real UNI-010 APIs and strict read-only Next adapters. Current-campus strict `CampusEntranceSchema` DTOs enter the gate layer; UNI-021 uses a separate strict `PublicPoiSchema` validator for eligible public POIs on the current bounded result page; invalid, duplicate, wrong-parent or generic boarding objects are rejected. Coordinates come from those public DTOs, never guessed pilot data. Markers are keyboard-operable buttons with source-aware labels and selection state. UNI-015 excludes markers covered by controls, sheet/preview or viewport clipping from visibility/tab order until a later unobstructed render; equivalent public list selection stays available. The render listener is removed with the map, and fitting after the ready legend mounts accounts for that overlay. Selecting a marker follows the same URL update and preview-focus path as a result or entrance selector.

The existing `university/campus/entrance/category/q/view` contract stays unchanged. Reload, share links and Back/Forward restore selection; campus/university changes clear incompatible markers immediately. Category/search filter marker membership exactly like results. A selected starting gate may remain in the preview while a name filter excludes it from results/markers, preserving UNI-012's explicit selection semantics. The camera fits visible public gates, centers a visible selected gate, or shows a neutral world view without a guessed campus. Free pan/zoom is local presentation, not arbitrary coordinate query state. No distance/routing calculation occurs.

Basemap features are independent public cartography, not UniHood-verified boarding/POI inventory, owner assertions or official vacancy/pricing. UniHood overlays public campus gates or the separate bounded public POI page (UNI-021), never a generic boarding/place object. Synthetic fixtures near (0,0) remain visibly fictional; they never stand for a real Sri Lankan campus. Community boarding recommendations, AREA_ONLY/HIDDEN advertisements, private evidence/contact and owner publication remain outside map input. All five ADRs and existing server authorization controls remain unchanged.

## Loading, graphics and lifecycle

The installed [MapLibre documentation](https://maplibre.org/maplibre-gl-js/docs/) specifies the v6 ESM worker setup for Next: `new URL('maplibre-gl/dist/maplibre-gl-worker.mjs', import.meta.url)`. Next emits the worker as a hashed same-origin asset. Two shared workers are configured; no global prewarm keeps them alive. Runtime CSS is bundled locally. The unmodified BSD/third-party [engine license](../../apps/web/public/licenses/maplibre-gl.txt) is publicly served at `/licenses/maplibre-gl.txt` and linked from the privacy dialog. Update that notice with a library upgrade.

Client module loading has a ten-second timeout; provider initialization has a twelve-second timeout. Loading, missing/invalid config, resource/network error, WebGL construction failure and native context loss have explicit messages. Retry destroys the failed instance and constructs a new one; Map/List stays available. Mobile fallback actions fit above the expanded sheet. Raw exceptions/provider response text are not displayed.

A ResizeObserver handles viewport/rail changes; sheet changes update camera padding so gates/controls stay in usable map space. All markers, DOM listeners, map listeners, observers, timers and map instances are removed on errors, retries, route navigation or list mode. Late module results cannot initialize an unmounted/timed-out viewport. Repeated selection updates do not create another map. Panning/zooming use MapLibre keyboard/touch controls; list selection remains the equivalent accessible route. Attribution stays above the mobile sheet with readable links/touch targets.

Deployments applying CSP need same-origin workers and bundled assets plus `https://tiles.openfreemap.org` in relevant connect/image permissions; MapLibre documents `img-src` support for data/blob images. This issue does not invent a global site CSP or relax other guards. User geolocation and arbitrary geocoding are not requested. Public Nominatim bulk queries and Google Maps scraping are not used.
